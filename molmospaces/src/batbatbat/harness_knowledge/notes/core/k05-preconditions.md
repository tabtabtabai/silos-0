Before each step, confirm its precondition from the latest result: hand open and empty before approaching to grasp, the object held before carrying, the object over its destination before letting go. If you already hold what you need, carry it on instead of grasping again.
Why: acting on a state you assumed rather than read is the commonest way to undo progress.

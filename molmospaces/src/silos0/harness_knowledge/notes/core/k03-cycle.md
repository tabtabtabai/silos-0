Work one sub-goal at a time. Before each action, note in a line what result you expect to see; after it, compare the result with that expectation before choosing the next action. Re-plan from the current state rather than following an earlier plan.
Why: comparing against an expectation is how a miss gets noticed one step after it happens instead of five.
